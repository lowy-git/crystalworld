# 内核与数据规格 v0.1

> 配套 [设计计划](<设计计划.md>) 第 3、6、9 节。本文档只写"怎么算、怎么存、怎么验"，不含实现代码。
> 记号：**a₁ a₂ a₃** 为直接基矢，**b₁ b₂ b₃** 为倒易基矢，(hkl) 为晶面指数，[uvw] 为晶棱/晶带指数，**n** 为单位面法线，D 为中心距。

---

## A. 晶胞与坐标系约定

### A.1 参数定义

晶胞由 6 个参数确定：a, b, c（Å）与 α, β, γ（度）。α 是 **b 与 c** 的夹角，β 是 **a 与 c** 的夹角，γ 是 **a 与 b** 的夹角。

**约定（必须写死，且写进数据字段 `setting`）**：

| 项 | 约定 | 说明 |
|---|---|---|
| 单斜 | **b 轴唯一** | β ≠ 90°，α = γ = 90°；与 ITA 标准一致 |
| 六方/三方 | **四指数 (hkil)**，i = −(h + k) | 内部统一转三指数 (hkl) 运算 |
| 三方 | 同时支持 `hexagonal` 与 `rhombohedral` 两种取向 | 数据里存 `setting`，UI 可切换，两套指数自动换算 |
| 角度单位 | 数据存度（number），计算转弧度 | 不用字符串 |
| 手性 | 不做对映体区分（第一版） | 32 点群里 11 个手性群仅作标注 |

### A.2 直接基（笛卡尔实现）

取 a₁ 沿 x 轴：

```
a₁ = (a, 0, 0)
a₂ = (b·cosγ, b·sinγ, 0)
a₃ = (c·cosβ, c·(cosα − cosβ·cosγ)/sinγ, c·V*/sinγ)

V* = √(1 − cos²α − cos²β − cos²γ + 2·cosα·cosβ·cosγ)
V  = a·b·c·V*                （晶胞体积）
```

倒易基：**b₁ = (a₂ × a₃)/V**，其余循环。此时对任意 (hkl)，**g = h·b₁ + k·b₂ + l·b₃** 就是该面族的法线，且 **|g| = 1/d_hkl**。

> 这条等式是整个内核的支点：**面法线与面间距不需要查表，全部由 6 个参数算出来**——七大晶系的差别因此完全落在数字里。

### A.3 度规张量（用于快速写法线/夹角，避免叉乘累积误差）

```
G = ⎡ a²         ab·cosγ    ac·cosβ ⎤
    ⎢ ab·cosγ    b²         bc·cosα ⎥
    ⎣ ac·cosβ    bc·cosα    c²      ⎦
```

面角（两面夹角）：`cos φ = (g₁·g₂) / (|g₁|·|g₂|)`，其中 g = G*·(h,k,l) 在倒易空间计算，或直接用 A.2 的笛卡尔向量点乘。

### A.4 晶带

晶棱 [uvw] 同时属于 (h₁k₁l₁) 与 (h₂k₂l₂)：

```
u = k₁l₂ − l₁k₂,   v = l₁h₂ − h₁l₂,   w = h₁k₂ − k₁h₂
```

判定：(hkl) 属于 [uvw] ⟺ **hu + kv + lw = 0**。全整数运算，无误差。

### A.5 合法性与退化

- 范围校验：a, b, c ∈ [0.5, 50] Å；角度 ∈ (0°, 180°)；`cos²α + cos²β + cos²γ + 2cosαcosβcosγ < 1`（否则体积虚数）。
- 接近退化的晶胞给警告而非报错（例如 β = 89.9° 的单斜，视觉上就是斜方）。

## B. 晶面 → 面族（对称生成）

### B.1 点群表示

32 个点群全部用 **3×3 整数矩阵**表示，作用在 (hkl) 列向量上，在**该晶系的常规基**下（六方用三指数基）。整数矩阵的好处：不会累积浮点误差，(hkl) 去重可以精确比较。

**强制自检（写代码前就要能跑）**：

1. 每个矩阵 det = ±1；
2. 集合对乘法闭合；
3. 每个元素有逆；
4. 阶数等于下表（不符即为抄写错误）。

### B.2 32 点群与阶数

> 晶类中文名（六八面体类、复三方偏三角面体类……）与"该晶类允许哪些单形"作为**内容任务**单独编写核对，不塞进代码表里。

### B.3 面族生成

```
formFaces(hkl, G) = unique{ M·(h,k,l) : M ∈ G }  对 ±1 取模去重
```

- 去重规则：(hkl) 与 (−h−k−l) 是同一个面，取符号规范化（首个非零分量为正）。
- 面数 = |G| / |Stab(hkl)|。稳定化子越大，面越少（如 {100} 在 m-3m 中只剩 6 个面）。
- 六方/三方：输入 (hkil) 先转 (hkl)，生成后再补 i 显示。

## C. 多面体求解（核心算法）

### C.1 输入输出

```
输入：晶胞 cell、点群 G、晶形表 forms = [{hkl, k}]（k 为相对生长权重）
输出：{
  vertices: Vec3[],           // 世界坐标，已归一化到单位包围球
  faces:    { planeId, vertexIdx[], normal, D }[],
  edges:    [i, j][],
  faceForm: number[],         // 每个面对应的晶形序号（用于上色与解释）
  visibleForms: number[],     // 实际出现在凸包上的晶形
  isOpen: boolean             // 半空间不封闭（开形）
}
```

### C.2 步骤

1. **面法线**：对每个晶形生成 (hkl) 族 → 每个面的 **n**（单位化）与 d。
2. **中心距**：`D_i = k_i · d_i`（默认 k = 1，即唐奈-哈克近似：面间距越大，面越发育）。
3. **合并**：法线相同（n_i·n_j > 1 − 1e−8）时只保留 **D 最小**的那个面（更靠内的面永远被挡住）。
4. **候选顶点**：枚举所有三元组 (i,j,k)，解
   ```
   x = [D_i(n_j×n_k) + D_j(n_k×n_i) + D_k(n_i×n_j)] / (n_i·(n_j×n_k))
   ```
   |det| < 1e−9 跳过；保留满足所有 `n·x ≤ D + tol` 的点。
5. **去重**：位置差 < 1e−6 视为同一点。
6. **凸包**：对候选顶点做 QuickHull → 三角面 → 按法线合并共面三角形 → 多边形面；每个面绑定 planeId。
7. **棱**：两两相邻面的公共边。
8. **归一**：平移到质心，缩放包围球到 1（渲染尺度与参数解耦）。
9. **开形检测**：若某面在凸包上找不到归属，或半空间集合无界 → `isOpen = true`，并给出"缺哪一类面才能闭合"的建议。

**容差**：所有比较用相对容差（相对 max D）。典型面数 < 200，复杂度 O(m³) 完全够用；如遇 m > 500（多组高指数晶形）改用"逐面裁剪"增量算法。

### C.3 自检断言

- 欧拉公式：**V − E + F = 2**（凸多面体）。
- 所有顶点满足所有面不等式（容差内）。
- 每个面至少 3 个顶点，法线朝外（n·(x_face − centroid) > 0）。
- 面数 ≤ 输入面族总数，且 visibleForms ⊆ 输入晶形。

### C.6 与参考实现的一致性（外部佐证）

这不是我发明的算法。Steffen Weber 的 Crystal Shape Applet（Mindat 晶形展示的技术源头）明说 *"this applet **calculates the crystal shape from a (hkl)-list**"*，即是本节这 8 步；同一家的 WinWULFF 用同一份 (hkl) 数据出赤平投影。两点结论：

1. 方案 A 的**输入形态**（(hkl) 列表 + 权重）与成熟工具一致，数据可互抄、可核对；
2. §F 的赤平投影**不要另建数据源**——直接复用 §B 展开后的面族法线做 `r = tan(ρ/2)` 投影，3D 与投影永远同步。

我们比参考实现多出来的自由度只有三条：`k` 可连续调、晶胞 6 参数可调、双晶用矩阵而非第二份手绘。

## D. D 值的语义（形态是否好看的唯一旋钮）

三种模式并存，UI 上明确标注：

| 模式 | 公式 | 用途 |
|---|---|---|
| 几何理想 | D = 1（所有面等距） | 纯讲晶系与对称，形态"均整" |
| 唐奈-哈克（默认） | D = k · d_hkl | 接近教科书形态，面间距大的面更发育 |
| 文献拟合 | D = d_hkl · kᵢ，kᵢ 由标本/图版拟合 | 复现具体产地标本的形态 |

**消面判据**：某晶形的所有面顶点都落到其他半空间之外 → 该晶形不可见。程序要能说出"被谁切掉"（记录让该面顶点失效的约束编号）。

**为什么开形会失败**：六方柱 {10-10} 只有 6 个竖直面，半空间沿 c 轴无界 → 求交不封闭。程序据此提示"开形需与另一组晶形组合"，这与教材结论一致，且是**算出来的**而不是写死的。

## E. 双晶

### E.1 操作定义

双晶操作 T 是一正交矩阵，**不属于**该晶体点群 G：

- 反映（双晶面，单位法线 **m**）：`T = I − 2·m·mᵀ`
- 二次旋转（双晶轴，单位轴 **u**）：`T = 2·u·uᵀ − I`
- 一般旋转（轴 **u**，角 θ）：罗德里格斯公式

第二个个体 = 第一个个体整体施加 T。**接合面**（composition plane）单独记录，用于接触型双晶的裁剪。

### E.2 校验规则

1. **合法性**：T ∉ G（否则不是双晶而是对称操作）。黄铁矿"铁十字"就是最好的例子：m-3 里没有四次轴，所以绕 [001] 转 90° 是一个合法的双晶操作——这一句解释直接来自群论，可以显示在 UI 上。
2. **格相容**：T 应把某个超格点阵映到自身（重合点阵）。第一版做"近似检查"：T 作用后的低指数面仍接近有理指数即通过，并在数据里标注 `latticeCompatible: true/false/unknown`。
3. **双晶角**：对应面法线夹角 `φ = arccos(n · T·n)`；接触双晶的**凹角** = 180° − φ。全部由引擎计算，不写死数字（这样才能"改参数读数跟着变"）。

### E.3 渲染策略

- 贯穿型：两个个体半透明叠加，可选"错位量"滑杆；
- 接触型：沿接合面做半空间裁剪（不需要 CSG，裁剪多边形即可）；
- 聚片型：同一操作重复 N 次（N 可调），沿接合面平移；
- 叠加显示：双晶面/双晶轴/接合面，凹角红折线 + 数值。

`mechanism` 取值（对应设计计划 §4.5 的四类成因，教学卡按此归类）：

| 值 | 中文 | 原理一句话 | 典型 |
|---|---|---|---|
| `growth` | 生长双晶 | 两个晶核按双晶律取向连生，界面能低到划算 | 萤石 {111}、尖晶石律、十字石 |

### G.5 字段约束

- `hkl`：整数数组，长度 3（或 4，六方/三方）；不得全 0；
- `k`：0 < k ≤ 10；
- `confidence`：`high | medium | pending`；**`pending` 的记录不得进入正式构建**（CI 门禁）；
- `sources`：至少 1 条；双晶律至少 2 条独立来源；

## H. 内核 API（实现时的函数签名）

```ts
type Vec3 = [number, number, number];
type Hkl = [number, number, number] | [number, number, number, number];
type Cell = { a: number; b: number; c: number;
              alpha: number; beta: number; gamma: number };
type FormSpec = { hkl: Hkl; k: number };

buildMetric(cell: Cell): { G: number[][]; Ginv: number[][];
                           basis: Vec3[]; reciprocal: Vec3[]; volume: number };

faceNormal(hkl: Hkl, m: Metric): { n: Vec3; d: number };
interfacialAngle(h1: Hkl, h2: Hkl, m: Metric): number;      // 度
zoneOf(h1: Hkl, h2: Hkl): [number, number, number];
formFaces(hkl: Hkl, group: string): Hkl[];                  // 去重后的面族

buildPolyhedron(forms: FormSpec[], cell: Cell, group: string):
  { vertices: Vec3[]; faces: Face[]; edges: [number, number][];
    faceForm: number[]; visibleForms: number[]; isOpen: boolean };

twinTransform(el: TwinElement): number[][];                 // 3×3
twinAngle(n: Vec3, T: number[][]): number;                  // 对应面夹角
```

约束：`core/` 不 import three.js、不读文件、不依赖 DOM；输入纯数据、输出纯数据。

## I. 锚点回归测试表

### I.1 面角（用真实晶胞参数算，与文献值比）

| 检查 | 期望值 | 说明 |

## J. 内容核对协议

1. **来源优先级**：教材（潘兆橹《结晶学及矿物学》、Klein & Dutrow《Manual of Mineral Science》、HMM）> Mindat > Webmineral > Wikipedia。
2. **几何数据一律自算**：只录入 a, b, c, α, β, γ 与 (hkl)，面角、面数、双晶角由引擎导出——这样既避免抄错，也规避版权问题。
3. **双来源规则**：双晶律的双晶面/轴、接合面、双晶角必须两个独立来源一致；不一致则标 `pending`，进 `docs/pending.md`。
4. **每条记录带日期**：`checked: "YYYY-MM"`，方便日后复核。
5. **构建门禁**：`confidence: pending` 的条目在 `pnpm build:prod` 时被剔除；`pnpm verify` 检查 Schema 与来源完整性。
