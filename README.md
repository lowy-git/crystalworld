# CrystalWorld · 晶体世界

> 一个从**晶胞参数**长出晶体、转着看、还能讲清"为什么长成这样"的交互式结晶学小工具。
> 现在就能玩：[demo/crystal.html](demo/crystal.html) —— 单文件、离线、**双击即开**，不用装任何东西。

## 现在能玩什么

- **12 种矿物、28 个外形、125 个变体**，覆盖全部七大晶系（等轴 / 三方 / 六方 / 四方 / 斜方 / 单斜 / 三斜）
- 萤石、石榴石、白钨矿、绿柱石、石英、方解石、文石、石膏、钠长石、黄铁矿、钻石、黄玉，每种都带真实晶胞参数与常见色
- 每种的「认识它」面板用人话讲：它是什么、哪儿能见到、有多硬、怎么认
- 每个外形可以**逐个勾选单形**：取消勾选不是"挖掉一块"，而是剩下那些面重新闭合成完整晶形
- 左键拖着转、滚轮缩放、右键平移；晶轴会画出来，被晶体挡住的那段自动变虚线
- 四种质感（蜡状 / 玻璃 / 金刚 / 金属）**与**三档通透度是**两个独立栏位**，透明度单独一条滑杆
- 五套场景（**空白** / 实验台 / 自然 / 藏品柜 / **纸面 3D**）：纸面是真 3D 台面——桌子、纸张与晶体共用同一深度缓冲，透视自动匹配、接触阴影是沿主光方向的真实投影（光位滑杆实时改变影子）；空白是影棚灰渐变；另外三套为实拍感照片（AI 生成）内联进单文件。可调光源方位与高度（主光 + 轮廓光 + 补光等六灯）
- 换矿物的默认染色＝该矿物**最具代表性的颜色**（萤石绿、黄铁矿金、水晶紫水晶……）；「按单形配色」是色块列表的最后一项
- 六种内含物（金红石针、电气石、黄铁矿、气泡、多相、愈合裂隙），数量与大小各一条滑杆
- 石英柱面的横纹、萤石立方面的对角纹、黄铁矿立方体的棱向条纹（可关）
- 双晶：萤石尖晶石律（两个立方体互相穿插）、石英日本律（两 c 轴夹角 **84°33′**，沿 {11-22} 贴合、下方晶头切平）、石英道芬律与巴西律（转变/反射双晶，外部看不出来，只画内部域界）、黄铁矿铁十字双晶
- 双晶可以拆开：接触双晶沿结合面分开，贯穿双晶沿双晶轴抽出，各自仍是完整个体
- 导出 PNG：4:3 / 9:16 / 16:9 三种画幅，**导出前先看预览**，所见即所得

## 打开方式

直接双击 `demo/crystal.html`。没有任何依赖、不联网、不构建。

## 想改的话

```bash
# 改数据（矿物、外形、单形、k 值、默认光泽/通透度）
#   spike/minerals.data.mjs

# 改界面/渲染
#   demo/crystal_template.html

# 重新生成 demo/crystal.html（需要 Node 18+）
node spike/make-app.mjs

# 跑一遍自动检查（185 条断言）
node spike/app-check.mjs

# 换场景背景图：替换 demo/bg/ 下同名 jpg（dark/lab/nature/cabinet/paper），
# 再跑一次 make-app 即可重新内联；重画可用 python spike/fetch-bg.py（AI 生图）
```

`spike/kernel.mjs` 是几何内核：晶胞 6 参数 → 度规与面法线 → 点群生成面族 → **所有半空间求交**得到凸多面体。面角、双晶角全部由同一套几何算出来，渲染层不参与任何结晶学计算。

背景照片的纪律：`BACKGROUNDS` 里带桌面的场景，`focus[1]`（照片里"可站立表面"所在的行）必须等于 `table.y`——焦点行被精确钉在画布同一比例处，任何窗口比例下贴桌都不会悬空。

## 老实说几句

- 这些是**理想形态**，不是真实生长模拟。长得直、长得标准，是为了把面与面之间的关系看清楚。
- 每个单形的大小倍率 `k` 是手工调的定性参数（不是 BFDH 算出来的），只改相对大小、不改面族。
- 晶纹、玻璃质感和双晶接合处的观感，还需要对着真实标本照片继续调。
